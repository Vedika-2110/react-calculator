Calculator App:

A simple Calculator built using React (Frontend) and Node.js/Express (Backend).

🚀 Features:
- Basic operations (+, -, *, /)
- Clear & Delete buttons
- Simple UI

📁 Structure:
frontend/ - React App  
backend/ - Node Server  

▶️ Run Project

### Frontend
cd frontend  
npm install  
npm start  

### Backend
cd backend  
npm install  
node server.js
